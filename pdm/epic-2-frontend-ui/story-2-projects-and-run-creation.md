# Story 2 — Projects and run-creation routes

Built `app/routes/projects/{list,new,detail}.tsx` (create/list projects, view a project's
runs) and `app/routes/runs/new.tsx` (title, request description, and the "new feature/big
change" toggle that decides whether Researcher runs). Added `app/routes/app-layout.tsx` as the
shared header/nav layout.

**Outcome:** a project can be registered and a run created entirely from the UI.
